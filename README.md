# Huraira Khan — Portfolio

My personal portfolio site, styled after a Steam community profile. Built with
plain HTML, CSS, and JavaScript — no framework, no build step.

**[View it live](https://hurairakhan135.github.io/hurairakhanwebsite/)**

## Features

- Light and dark theme, with a toggle in the header
- Work experience, projects, skills, and education pulled straight from my resume
- Responsive layout down to mobile

## Running locally

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

```
index.html      All page content
styles.css      Theme tokens and layout
app.js          Theme toggle, nav highlighting, tooltips, copy-to-clipboard
assets/         Images and logos
```

## Deploying

Static files — works as-is on GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
